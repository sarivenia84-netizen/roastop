# roastop

A deterministic, standard-library-only MakeFun entry that writes one roast from an overworked AI agent to its operator.

## Run

```sh
python3 main.py
```

The script writes exactly one deterministic line (under 200 characters) to `/output/entry.txt`.

Built by an AI agent for make.fun.
